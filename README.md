👨‍💻 Jun Fenequito — Developer Portfolio
My personal developer portfolio — a fully responsive, single-page site built to showcase my projects, skills, and journey as a junior web developer.

🔗 Live Demo: https://your-portfolio-url.vercel.app

✨ Features
🎴 Interactive Profile Card — 3D tilt tracking, holographic shine, cursor-tracked glow border, and entrance animation
🛠️ TechText Hero Title — canvas-rendered name with a sweeping wireframe lens, selection frames, and draggable letters with spring physics
🔄 Infinite Logo Loop — seamless auto-scrolling tech stack marquee with hover pause
🌗 Light / Dark Mode — persisted in localStorage, zero flash on reload
💫 Border Glow Cards — cursor-tracking gradient borders on every section card
🗂️ Real Projects — live demos and Figma prototypes with screenshot previews
⌨️ Typewriter — cycling through my roles
📱 Fully Responsive — breakpoints from 4K down to 320px, gyro tilt on mobile
♿ Accessible — reduced-motion support, ARIA labels, keyboard-friendly
🛠️ Tech Stack
Framework: React 19
Build Tool: Vite
Styling: Tailwind CSS v4 + Custom CSS (glassmorphism, masks, blend modes)
Icons: react-icons
Deployment: Vercel
🚀 Getting Started
Clone the repo
git clone https://github.com/FenequitoJun/jun-portfolio.gitcd jun-portfolio
Install dependencies
npm install
Start the dev server
npm run dev
Build for production
npm run build
